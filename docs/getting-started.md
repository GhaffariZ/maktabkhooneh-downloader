# راهنمای استفاده از کتابخانه‌ی مطالعه

## نصب و اجرا

۱. ‏Node.js نسخه‌ی ۲۲ یا بالاتر را روی Windows، macOS یا Linux نصب کنید.

۲. از [صفحه‌ی نسخه‌ها](https://github.com/GhaffariZ/maktabkhooneh-downloader/releases) فایل **Source code** را دانلود و استخراج کنید. ترمینال را در پوشه‌ای باز کنید که `package.json` در آن قرار دارد.

۳. وابستگی‌ها را نصب کنید، برنامه را بسازید و آن را اجرا کنید.

```sh
npm ci
npm run build
npm start
```

اگر مرورگر خودکار باز نشد، نشانی `http://127.0.0.1:3210/` را مستقیم در نوار آدرس وارد کنید. برای اجرای برنامه بدون باز کردن مرورگر از `npm start -- --no-open` استفاده کنید. با `Ctrl+C` در ترمینال می‌توانید برنامه را متوقف کنید.

## ورود و مرور دوره‌ها

- **حساب کاربری** را باز کنید و با ایمیل و رمز عبور مکتب‌خونه وارد شوید. دوره‌های قابل‌دسترسی در **دوره‌های من** نمایش داده می‌شوند.
- اگر دوره‌ای که به آن دسترسی دارید در فهرست نبود، از **بروزرسانی** یا **افزودن با پیوند** استفاده کنید. پیوند صفحه‌ی دوره یا درس در LMS پذیرفته می‌شود.
- داخل هر دوره می‌توانید درس‌ها را جست‌وجو کنید، فصل‌ها را باز کنید و فهرست را بر اساس وضعیت مشاهده فیلتر کنید.

## پخش و دانلود یک درس

- **پخش** کنار هر درس را انتخاب کنید و کیفیت موجود را تأیید کنید. در منوی تنظیمات پخش‌کننده می‌توانید سرعت را تغییر دهید.
- برای تماشای آفلاین، **دانلود** را کنار همان درس بزنید و کیفیت را انتخاب کنید. پس از پایان دانلود، از **دانلودها و آفلاین** فایل محلی را پخش کنید. هنگام تماشای آفلاین، سرور محلی باید در حال اجرا باشد.
- دانلودهای فعال را می‌توانید متوقف، ادامه یا لغو کنید. مسیر پیش‌فرض فایل‌ها `Downloads/Maktabkhooneh` در پوشه‌ی خانگی شماست. برای تغییر آن، **تنظیمات** برنامه را باز کنید.
- فقط از محتوایی استفاده کنید که به آن دسترسی دارید و اجازه‌ی ذخیره‌ی آن را دارید.

## پیشرفت و میانبرها

داشبورد زمان پخش و درس‌های مشاهده‌شده را ذخیره می‌کند. برای بازگشت به آخرین درس از **ادامه‌ی یادگیری** در کتابخانه استفاده کنید. وضعیت مشاهده‌ی هر درس را در فهرست سرفصل‌ها هم می‌توانید تغییر دهید.

| کلید | عملکرد |
| --- | --- |
| `J` | ده ثانیه عقب، وقتی پخش‌کننده در فوکوس است |
| `K` | پخش یا مکث، وقتی پخش‌کننده در فوکوس است |
| `L` | ده ثانیه جلو، وقتی پخش‌کننده در فوکوس است |
| `F` | ورود یا خروج از نمای تمرکز |
| `Esc` | بستن منوی باز پخش‌کننده یا خروج از نمای تمرکز |

تنظیمات نما، سرعت پیش‌فرض و تاریخچه‌ی مطالعه برای همان مرورگر، پروفایل و نشانی محلی ذخیره می‌شوند. تغییر مرورگر، پورت یا پاک کردن داده‌های سایت روی دسترسی به تاریخچه تأثیر می‌گذارد.

## حالت نمایشی و رفع اشکال

- `npm start -- --demo` دوره‌ها و فایل نمونه را با داده‌های جداگانه اجرا می‌کند و برای امتحان برنامه به حساب مکتب‌خونه نیاز ندارد.
- اگر پورت ۳۲۱۰ اشغال است، از `npm start -- --port 3211` استفاده کنید و `http://127.0.0.1:3211/` را باز کنید.
- اگر پخش آنلاین خطا داد، وضعیت ورود و کیفیت‌های موجود را بررسی کنید. اگر فایل دانلودشده پخش نشد، بررسی کنید که فایل و پوشه‌ی دانلود هنوز در دسترس باشند.
- اطلاعات نشست، فهرست دوره‌ها و صف دانلود در `data/app-state.json` در پوشه‌ی برنامه قرار دارند. گذرواژه در این فایل ذخیره نمی‌شود. فایل نشست را خصوصی نگه دارید.
